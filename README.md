# AI Career Coach — Landing Page

A static frontend prototype for an AI-powered career coaching platform. The current repository contains a landing page built with HTML, CSS, and JavaScript.

## Page Sections

- Hero section introducing the product concept
- Career-support feature cards
- AI agent overview
- Login and call-to-action buttons (visual elements)

## Tech Stack

HTML, CSS, and JavaScript.

## Project Structure

```text
ai-career-coach/
├── index.html
├── style.css
├── app.js
└── README.md
```

## Run Locally

Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/gopalrajane/ai-career-coach.git
cd ai-career-coach
```

No build step or package installation is required.
